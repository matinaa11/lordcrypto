# ربات رصد و ارزیابی هوشمند سیگنال‌های طلا (@lordxau)

این ربات به‌صورت خودکار و ۲۴ ساعته نسخه وب کانال تلگرامی **Lord Crypto (@lordxau)** را رصد می‌کند. پیام‌های اسپم و تبلیغاتی را فیلتر کرده و با تطبیق سیگنال‌ها با **قیمت لحظه‌ای طلای جهانی (XAUUSD)**، سود و زیان دلاری هر معامله را حساب می‌کند.

---

### ✨ قابلیت‌ها:
1. **راه‌اندازی فوق‌سریع بدون نیاز به API ID یا لاگین به تلگرام:**
   * سیستم از وب‌پایش مستقل استفاده می‌کند؛ نیازی به `my.telegram.org` یا سشن ندارد.
2. **محاسبه سود و زیان دلاری بر مبنای سرمایه شما (مثلاً ۲ دلار):**
   * سود دلاری، درصد بازدهی و فاصله تا استاپ را برای هر سیگنال به دلار اعلام می‌کند.
3. **دکمه‌های شیشه‌ای لمسی (Inline Keyboards):**
   * دکمه‌های `[ ✅ وارد این معامله شدم ]` و `[ ⏭ نگرفتم ]` زیر هر سیگنال برای تفکیک معاملات شخصی شما.
   * دکمه‌های بررسی آنی قیمت طلا، مشاهده کارنامه و تغییر سرمایه با یک لمس.
4. **شماره‌گذاری متوالی سیگنال‌ها:** (`سیگنال شماره #1`، `#2` و...).
5. **گزارش خودکار پایان روز (ساعت ۲۳:۰۰):**
   * کارنامه روزانه با محاسبه سود/زیان شخصی شما و کل کانال.
6. **تشخیص برد و باخت معامله (WIN / LOSS):**
   * اعلام قطعی نتیجه پس از تاچ استاپ یا تحقق تارگت.

---

## 🛠 پیش‌نیازها (فقط ۲ مورد!)

1. **توکن بات تلگرام (BOT_TOKEN):**
   * در تلگرام به [@BotFather](https://t.me/BotFather) پیام دهید و دستور `/newbot` را بفرستید. یک نام و آیدی انتخاب کنید و توکن را کپی نمایید.
   * **مهم:** وارد رباتی که ساختید شوید و یک‌بار دکمه **Start** را بزنید.
2. **آیدی عددی تلگرام شما (USER_CHAT_ID):**
   * در تلگرام به [@userinfobot](https://t.me/userinfobot) پیام دهید و عدد بخش `Id` را کپی کنید.

---

## ☁️ راه‌اندازی روی Railway در ۲ دقیقه

1. فایل‌های این پوشه را در یک ریپازیتوری در [GitHub.com](https://github.com) آپلود کنید.
2. وارد [Railway.app](https://railway.app) شوید و دکمه **New Project** را بزنید.
3. گزینه **Deploy from GitHub repo** را انتخاب کرده و ریپازیتوری خود را انتخاب نمایید.
4. وارد تب **Variables** در پروژه شوید و متغیرهای زیر را اضافه کنید:

| نام متغیر (Name) | مقدار (Value) |
| :--- | :--- |
| `BOT_TOKEN` | توکن ربات از BotFather |
| `USER_CHAT_ID` | آیدی عددی تلگرام شما |
| `TARGET_CHANNEL` | `lordxau` (پیش‌فرض) |
| `TRADE_BUDGET_USD` | `2.0` (یا هر مبلغ دلخواه شما به دلار) |

5. ریل‌وی به‌صورت خودکار ربات را بیلد کرده و ۲۴ ساعته اجرا می‌کند. به محض استارت، پیام خوش‌آمدگویی با قیمت زنده طلا و دکمه‌های شیشه‌ای در تلگرام شما ظاهر خواهد شد.
